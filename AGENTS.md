# Project rules

## Git
- Never add AI co-author trailers, Claude/GPT/MiMo attribution, or generated-by lines in commits or PRs.
- Keep commit messages short, human, and specific. No em dashes. Prefer plain sentences or a short subject line.

## Writing
- Do not use em dashes (—) in UI copy, articles, README text, or chat replies. Use commas, colons, periods, or parentheses instead.

## Content
- No client-confidential material on this site.
- Edit content in `assets/js/data.js` only when changing copy/data.
